> *Smart Route, Smart Delivery*

## 📖 ข้อมูลโครงการ (Project Overview)
โครงการนี้พัฒนาขึ้นตามข้อกำหนดและสถาปัตยกรรมที่ระบุในเอกสารนำเสนอโครงการ โดยเน้นแก้ปัญหาการบริหารจัดการรถบรรทุกขนส่งผลิตภัณฑ์ปิโตรเลียม (น้ำมันและก๊าซ LPG) ทั้งในประเทศและข้ามแดน จำนวน **13 คัน** (Volvo FM370 5 คัน, Scania P360 8 คัน) พร้อมพนักงานขับรถ **13 คน**

### ปัญหาที่พบในระบบเดิม (Pain Points):
1. **ติดตามขั้นตอนงานยาก:** ต้องคอยโทรศัพท์หรือสอบถามผ่าน LINE กับคนขับรถ
2. **ติดตามตำแหน่งรถยาก:** พึ่งพาผู้ให้บริการ GPS ภายนอก ข้อมูลกระจัดกระจาย
3. **ไม่มีศูนย์รวมข้อมูล:** เอกสารงาน ข้อมูลรถ คนขับ และประวัติการจัดส่งไม่เป็นระบบ

## 🌟 ฟังก์ชันและโมดูลหลักของระบบ (Features)

### 1. ระบบติดตามสถานะงานขนส่ง (Status Tracking Flow - FSM Engine)
ทำงานด้วยโมเดล Finite State Machine (FSM) แบบ Read-only Monitoring (คนขับอัปเดตผ่านมือถือ + มี Admin Override กรณีฉุกเฉิน) รองรับทั้ง:
* **งานขนส่งภายในประเทศ (7 ขั้นตอน):** รอรับงาน &rarr; ลงคิวคนขับ &rarr; ตรวจสภาพรถ &rarr; รับสินค้า &rarr; ออกเดินทาง &rarr; ส่งสินค้า &rarr; เสร็จสิ้น
* **งานขนส่งข้ามแดน / ต่างประเทศ (8 ขั้นตอน):** เพิ่มขั้นตอนที่ 6 **ส่งเอกสารข้ามแดน** (ยื่นใบขออนุญาตขนส่งสินค้าอันตรายข้ามแดน, กศก.120, ซีลศุลกากร)

### 2. ฟีเจอร์ติดตามตำแหน่งด้วย GPS (GPS Tracking & Live Map)
* แผนที่เรียลไทม์แสดงตำแหน่งรถทั้งหมดและคลังสินค้า พร้อมระยะทางคงเหลือและ Live ETA
* แสดงสถานะรถด้วยสี: กำลังวิ่ง (เขียว), จอดพัก (ส้ม), พร้อมใช้งาน (น้ำเงิน), ตรวจเช็ค (แดง)
* **โหมดเจาะลึก GPS รายคัน (Single-Vehicle Popup):** กดดูจากหน้ารถหรือแผนที่เพื่อแสดงเฉพาะรถคันเดียว เส้นทางวิ่งจริง รายละเอียดงาน และสถานะงานครบในหน้าต่างเดียว

### 3. ระบบคำนวณเวลาการส่งและเวลาพักรถอัตโนมัติ (Embedded ETA & Safety Rest Engine)
* ฝังการทำงานในหน้าสร้างงาน (Auto Preview), หน้าติดตามสถานะ (Milestones Modal), หน้าแผนที่ GPS, หน้าจอมือถือคนขับ และหน้าติดตามของลูกค้า
* **ระบบคำนวณเวลาพักรถอัตโนมัติ:** ตามกฎความปลอดภัยการขนส่งวัตถุอันตราย (ขับต่อเนื่องครบทุก 4 ชั่วโมง ต้องหยุดพักรถอย่างน้อย 30 นาที) พร้อมคำนวณเวลาถึงปลายทาง (ETA) และเวลากลับถึงบริษัท

### 4. ฟีเจอร์สร้างงานและจัดรอบรถ (Route & Task Assignment Wizard)
* ขั้นตอน Wizard สำหรับผู้ดูแลระบบ:
  1. เลือกรูปแบบเส้นทาง (ภายในประเทศ 7 ขั้นตอน / ข้ามแดน 8 ขั้นตอน พร้อม Auto-detect)
  2. ระบุข้อมูลงาน ลูกค้า ประเภท/ปริมาณสินค้า จุดรับและจุดส่งสินค้า
  3. เลือกรถและคนขับที่พร้อมใช้งาน
  4. คำนวณ ETA และกฎพักรถ 4 ชม. แบบเรียลไทม์ก่อนยืนยันมอบหมาย

### 5. ฟีเจอร์จัดการรถและคนขับ (Fleet Management)
* ข้อมูลรถบรรทุกเริ่มต้น 13 คัน (Volvo FM370, Scania P360) และพนักงานขับรถ 13 คน (ใบขับขี่ ท.4)
* รองรับการ **เพิ่มพนักงานขับรถใหม่** และ **เพิ่มรถบรรทุกคันใหม่** (ทั้งเพิ่มพร้อมกันตอนลงทะเบียนพนักงาน หรือเพิ่มรถเข้ากองรถโดยตรง)
* กดดู GPS เจาะลึกรายคันพร้อมเส้นทางและสถานะงานได้ทันทีจากบัตรรถแต่ละคัน

### 6. ฟีเจอร์ประวัติงานและรายงาน (History & Audit Trail)
* บันทึก Log ทุกการเปลี่ยนแปลงสถานะ พร้อม Timestamp และชื่อผู้บันทึก

### 7. ช่องทางใช้งาน 3 บทบาท (Multi-Role Support):
* **ผู้ดูแลระบบ (Admin Dashboard):** เปิดผ่าน [`index.html`](./index.html)
* **พนักงานขับรถ (Driver Mobile App):** เปิดผ่าน [`driver.html`](./driver.html)
* **ลูกค้า (Customer Tracking Portal):** เปิดผ่าน [`track.html`](./track.html)

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์โดยตรง
* เปิดไฟล์ [`index.html`](./index.html) ใน Google Chrome หรือ Microsoft Edge ได้ทันที

### วิธีที่ 2: รันผ่าน Local Web Server (แนะนำ)
* ดับเบิลคลิกที่ไฟล์ **`start-server.bat`**  
  หรือรันคำสั่งใน PowerShell:
  ```powershell
  .\start-server.ps1 -Port 8080
  ```
* ระบบจะเปิดเว็บเบราว์เซอร์อัตโนมัติที่ `http://localhost:8080`
